# SSA005 — Equality with an unannotated value

| Severity | Code fix | Applies with `dotnet format` |
|----------|----------|------------------------------|
| Warning  | Yes      | Yes |

The equality counterpart of [SSA002](SSA002.md). Fires on `==` / `!=` when one operand carries an annotation and the other resolves to a declaration that has none.


## Example

```cs
public class Holder
{
    [StringSyntax(StringSyntaxAttribute.Regex)]
    public string Pattern { get; set; }

    public string Other { get; set; }

    public bool Same() => Pattern == Other;
}
```

Build output:

```
SSA005: property 'Holder.Pattern' is [StringSyntax("Regex")] but is compared with property 'Holder.Other', which has no StringSyntax attribute. Fix: add [StringSyntax("Regex")] to property 'Holder.Other' (line 6).
```

As with SSA002, the attribute named is the one that fits the bare side's declaration kind — `[ReturnSyntax(...)]` for a method, a `// language=` comment for a local, `[UnionSyntax(...)]` when the annotated side is a union.


## How to fix

Pick one:

1. **Annotate the bare side.** Add the attribute from the message to its declaration. This is what the code fix does.
2. **Rename the bare side** so a name convention infers the syntax, when `stringsyntax.name_conventions` is enabled.
3. **The two values hold different syntaxes.** Then the comparison is the bug.

Apply option 1 across a whole project:

```
dotnet format analyzers --diagnostics SSA005
```


## When it does not fire

 * The bare operand is **Unknown** — a literal, an unannotated local, a concatenation, an `await`. `pattern == ""` does not warn.
 * Either operand is `[StringSyntax("*")]`.
 * The bare operand is `object`, an unannotated generic `T`, or another generic value slot.
 * The bare operand is declared in a namespace matched by `stringsyntax.suppressed_target_namespaces`, or in an assembly known to carry no `[StringSyntax]` anywhere.
 * The bare operand's **name** already matches the annotated side's syntax convention.


## Suppressing

```cs
#pragma warning disable SSA005 // <reason the bare side should stay unannotated>
```

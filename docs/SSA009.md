# SSA009 — Member returns a tagged value but has no return annotation

| Severity | Code fix | Applies with `dotnet format` |
|----------|----------|------------------------------|
| Warning  | Yes      | Yes |

Fires when every `return` in a member's body resolves to the same annotated syntax, but the member's own signature carries none. The syntax stops at the API boundary: callers see a bare `string` and every downstream flow goes Unknown.


## Example

```cs
public class Row
{
    [StringSyntax("Html")]
    public string Reason { get; set; }

    public string Describe() => Reason;
}
```

Build output:

```
SSA009: method 'Row.Describe' returns a value tagged "Html" but carries no return annotation. Fix: add [ReturnSyntax("Html")] to method 'Row.Describe' (line 6).
```

The warning is reported on the member's *identifier* so the squiggle is tight, while the fix lands on the whole declaration.

The attribute named depends on the member kind:

 * A **method** or local function gets `[ReturnSyntax("...")]` — `StringSyntaxAttribute` has `AttributeUsage(Field | Parameter | Property)` and cannot describe a return value. See "`[ReturnSyntax(...)]` on methods" in the readme.
 * A **property** gets `[StringSyntax("...")]` on the property itself.

With shortcut attributes enabled, the fix offers the bare `[return: Html]` form instead.


## How to fix

Annotate the return:

```
dotnet format analyzers --diagnostics SSA009
```

Or, if the member genuinely returns something other than the body's syntax — it escapes, encodes, or reformats on the way out — then the body is what needs changing, and the returned value should be annotated to match.


## When it does not fire

 * The member already carries a return annotation (`[ReturnSyntax]`, `[return: Html]`, or `[StringSyntax]` on a property).
 * The returns **contradict** each other — two branches resolving to different syntaxes. The analyzer has no single value to suggest, so it stays silent rather than picking one.
 * Any return resolves to **Unknown** — a literal, a concatenation, an `await`, an unannotated local.
 * The member returns the wildcard `[StringSyntax("*")]`.

Returns nested inside a lambda, local function, or query clause belong to that inner symbol, not the enclosing method — they are analysed as their own member.


## Suppressing

```cs
#pragma warning disable SSA009 // return type is deliberately opaque to callers
```
